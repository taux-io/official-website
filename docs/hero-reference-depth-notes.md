# 景深／模糊／折射／格子質感 量測筆記
素材：淺色 1944x1760（24.5 s）、暗色 1988x1734（26 s）。方法：ffmpeg 抽幀（1 fps、2 fps、30 fps 連拍 3 s、原生 57 fps 連拍 100 幀）+ numpy 逐格量（格 16x24 px，淺色格線起點 x=11,y=1，暗色 x=5,y=18）。腳本在 scratchpad/d/（an.py a2~a5.py t1~t4.py nat.py tint.py spd.py dk.py pick.py crop.py）。標「確定」＝直接量到、重複幀都成立；「推測」＝間接推論。

## 結論先寫
1. 影片沒有「遠近淡糊」的分層。深淺不是用「遠景淡、近景濃」做的：三隻鯊魚的整體明度、速度都一樣（見 §1），差別只在大小與色偏。「深淺感」來自每隻鯊魚內部的密度場（脊線濃、側緣淡），邊緣約 3 格漸層。
2. 沒有畫面級或局部高斯模糊（格塊邊緣 1 px 銳利）。「模糊感」＝邊緣密度 3 格漸層 + 最外圈只剩無底的小字（o , ' `）+ 尾端半透明空白方塊。唯一真模糊是輸入框的毛玻璃（backdrop blur，前次量 20–30 px）。
3. 沒有水面折射／焦散／沿身體的亮度波。格與格之間的亮度變化幾乎不相關（相關係數 0.0~0.07）。「水感」最像來自：字元與色彩閃爍（每格每 17 ms 約 20% 機率重抽）、緩慢的身體彎曲、霧罩。折射是否存在：量不到（確定量不到相干波紋）。
4. 格子質感：每格是平面色塊，14x22 px（格 16x24 內縮，留 2 px 縫），字白色、無漸層。深淺色版同結構，僅極性反轉。

## 1 深淺分層（鯊魚之間）
- 畫面裡固定是 3 隻個體，兩支影片一致，以格底色偏（R−B）區分，確定：
  - 暖棕（R−B ≈ +17～+20）：小。完整時 41～96 個底格（中位 76），外框約 21–33 x 14–17 格（淺色 t0.25 為 21x17、暗色 t0.75 側視為 33x7），長軸約 25–28 格。
  - 冷藍灰（R−B ≈ −9～−16）：中。170～250 底格，31–36 x 13–16 格（錘頭）。
  - 中性灰（R−B ≈ +1～+8）：大。220～380 底格，39–54 x 20–22 格，長軸最長約 47–54 格。
  - 長度比約 小:中:大 ≈ 1 : 1.3 : 1.8（確定量到大小；是否有意當作遠近：推測）。
- 明度：三者差不多（確定）。淺色版格底灰階（0–255，越小越深）：暖 平均 138–150、冷 126–142、中性 120–154（受霧罩影響大）；核心 p25 約 101–119。暗色版底格亮度平均 69–124，p90 106–148，各隻差異小於同一隻不同幀的差異。大隻的格數與平均亮度相關係數僅 0.36（弱、方向反：大的反而略淺，因被霧罩蓋到）。
- 速度：暖 6.4 / 冷 6.1 / 中性 7.1 格/s（淺色，中位）；暗色 8.8 / 4.6 / 7.8。沒有視差差異（確定：無「近的快遠的慢」）。
- 所以「較淡較糊的遠景鯊魚」不存在；深度感唯一線索是大小不同＋重疊時沒有遮擋（推測）。
- 同一隻內部的深淺（確定）：整體底格灰階分布連續，淺色版 5/50/95 百分位 = 80 / 132 / 216（含邊緣），最深格約 28–36（近黑，常出現 @ 8 字）。暗色版 5/25/50/75/95/99 = 39/74/102/120/190/216。暗色的最亮格（約 190–220）是身體中脊的「高光」，淺色版對應為最深格。

## 2 模糊／景深
- 邊緣「真漸層」多格寬（確定）。以「離外緣第 k 圈」的底格亮度平均（淺色，值小＝濃）：k=1 187 → k=2 140 → k=3 109 → k=4 85（最深核心 ~30）。暗色：89 → 110 → 144 → 175（越進越亮）。換成「油墨密度」約為核心的 35–40% → 55% → 70% → 80%+，漸層寬約 3–4 格。不是只有邊緣格變淡。
- 邊緣最外層還有 1 圈「無底小字」（o , ' ` .）與「無字的淡色空方塊」（尾端常見，淺色版帶青灰色）：密度低於底格門檻時，底色先消失、只留小字，再整個消失。（確定，看放大圖）
- 單格內部沒有模糊：格塊邊緣 1 px 內由底色到縫（確定）。
- 無全畫面／局部高斯模糊（確定）。只有輸入框／History 按鈕的毛玻璃。
- 霧罩（halo）：淺色版是黑色低 alpha 的陰影，中心約 −11%（前次量）；中位數影像在搜尋框周圍橫向 y=1300 剖面：251 → 244，約離中心 0.6~1.0 個橢圓半徑時止。鯊魚進入霧罩區時對比被拉向背景（確定）：以橢圓半徑 r（中心 972,880；半徑 725 x 425 px）分組，淺色底格 r≥1.4：132 → r 0.6–1.0：165 → r<0.6：174（對比降約 33–40%）；暗色 108 → 63 → 52（降約 42–50%）。暗色版霧罩在背景上看不見（背景 0–1）。

## 3 水面折射／動態
- 底格亮度時間變化小（確定）：同一格 33 ms 後中位差 1.0、p90 8.5 灰階；267 ms 後中位 12（含位移）。→ 底色是平滑移動的密度場，不抖。
- 鄰格亮度變化相關（右 1 格 0.07、下 1 格 0.01、右 2 格 0.00、右 4 格 0.01）：無相干波紋／亮度波（確定）。
- 格子位移：輪廓每幀進出約 7% 的底格（每 33 ms 新增 14、消失 15 格 / 198 格），與鯊魚平移速度（6.5 格/s、周長約 100 格）推算相符 → 沒有額外的位移抖動，只是格點量化（確定量到數字；「無額外抖動」是推論）。
- 字元替換（確定）：原生幀（約 17 ms）每幀約 20%（15–29%，離群 40%+ 是編碼關鍵幀）的底格換字；30 fps 時 33 ms 後仍同字 63%，133 ms 後落到 26–29% 底線（亂數巧合水準）。→ 每格每個渲染幀獨立重抽，平均壽命約 60–70 ms，非固定頻率階梯（原生幀逐幀分布平，沒有週期）。重抽時底色幾乎不變（中位 4.3 vs 0.7）。
- 色彩字（確定）：約 11% 的底格字帶色（色度 ≥45），33 ms 後仍帶色 56%、66 ms 29%、99 ms 19%、400 ms 12%（≈基準）→ 與換字同步重抽，色彩亂數，格底仍灰。這個每格閃爍的彩色亮點是最像「折射光斑」的元素（推測）。
- 灰塵 '-'：前次量，原地閃爍 0.3–0.5 s。
- 身體起伏（量到，低信心）：暖色鯊魚 0–3.7 s 追蹤，沿主軸兩端橫向偏移由 +1.4 到 −0.9 格再回 0，是約 4 s 以上的慢彎，沒有 1 Hz 的擺尾；振幅 ±1 格，週期超過量測窗（≥ 4–5 s，推測）。尾端以格計幅度 0.5–1 格，和前次一致。

## 4 格子質感
- 格距 16x24 px；底格色塊 14x22 px，格內左、上各 2 px 縫（淺色版：第 0 px 為格線 ~240，第 1 px 為白 ~255，疑似 1 px 白描邊；右下縫屬於鄰格）。推測 DPR=2，CSS 即 8x12 px 的格、7x11 的色塊、1 px 縫。
- 底色平面，無漸層、無陰影；相鄰底格之間有明顯縫（白縫+淺灰格線），不是連成一片。
- 字：等寬字，墨跡約 9x13 px（寬 p10–p90 = 8–10、高 12–13），在 14x22 色塊內離上緣 4 px、左 1–2 px；字色近白（平均 206），在淺底上對比低。字尺寸全格一致（含灰塵 '-'）。
- 字元密度 ↔ 底色（確定）：底格 20–60 灰階時字墨覆蓋 ~53%（@ 8 %）；100–140：~40%（# S X t）；160–180：25%；180–200：7%（; : ,）；200–220：2.5%（o . '）。一個密度值同時決定底色濃度與字元。
- 底色曲線（淺色版）：油墨色約 (33,36,37) 到紙色 (252)，底格亮度＝紙 −(紙−墨)×密度。尚有暖棕組約 (87,82,71)、冷藍組偏藍。暗色：底格約 白 × 密度，核心 100–120，高光 190–220。
- 淺色 vs 暗色：同一套格、同一套字；極性反轉（暗色底格愈亮愈濃）；暗色背景 0–1 灰階，格線 ~11（白 4%）；暗色版高光格更突出（99 分位 216），淺色版最深 ~28。

## 5 輪廓裁圖（2 倍放大，格寬 32x48 px）
全在 .../scratchpad/ref/crops/：
- light_t0.25_*：暖、冷（兩隻完整）
- light_t2.25_*、light_t2.75_*、light_t3.25_*：三隻同框（暖、冷、中性）。t2.75／t3.25 的中性在霧罩中、較淡。
- dark_t0.75_warm_n71_33x7（側視小隻）、dark_t0.75_neutral_n383_54x22（最大最清楚）、dark_t6.25_cool_n253_24x22、dark_t4.75_*。
- 每隻特徵（看圖）：
  - 中性大隻（dark_t0.75 / light_t3.25）：54x22 或 44x21 格。錘頭（T 形）在上，寬約 31 格、厚 3–5 格，兩端微上翹；頸收窄到約 4–5 格寬；軀幹中段兩側各一胸鰭（斜向外伸約 4–5 格）；中脊最濃（暗色為最亮高光）；後段往下漸細，尾分兩叉（各 3–4 格，末端是無底的 o o）。
  - 冷藍中隻（light_t2.75 31–36x13–16、dark_t6.25 24x22）：錘頭較窄，長軸斜 30–45°，彎成 C/S 形，尾叉小。
  - 暖棕小隻（light_t0.25 21x17、dark_t0.75 33x7、dark_t4.75 28x14）：細長、窄身（寬 2–4 格）、尾叉窄；多半呈彎的細弧，沒有明顯寬頭（頭 4–5 格）。
  - 共同：寬度由中心往外 3–4 格漸層；尾端與鰭尖是淡底格＋小字，最外為無底小字。
- 逐格描形狀時建議以 dark_t0.75_neutral 為最佳參考（最完整、對比最高），light_t3.25 作為淺色對照。

## 未量到／不確定
- 沒做 OCR，字元對應密度是以字墨覆蓋率推。
- 被輸入框／標題遮住的鯊魚段落排除；霧罩下的格受毛玻璃影響。
- 視訊壓縮會製造 ±數灰階的雜訊與 ~1 s 關鍵幀尖峰；表中小於 5 灰階的差異不要當真。
- 身體擺動週期、DPR=2 皆為推測。
