{% call cover("01") %}先看這幾件事{% endcall %}

這一頁講的是 Matt Pocock 的 mattpocock-skills 外掛（MIT 授權）。外掛和裡面的每個 skill 都是他的作品；這份中文教學是拓思（TauX）自己寫的，不是官方文件，也不是翻譯。每個 skill 都是讀過它的 SKILL.md 之後，用自己的話重新寫成的。

先更正一個常見的說法：pr、retro、implement-spec 是 1.3.0 才升進正式清單，不是 1.3.1。1.3.1 只改了 ask-matt 的一段描述：診斷完 bug 之後，改指向 /retro，只有發現缺少 seam 時才指向 /improve-codebase-architecture。

用詞先說好。這一頁把外掛裡的每一份能力叫 skill；只有你親手在對話裡打的 /名稱 才叫指令。有些 skill 只能由你手打，有些由模型在適當的時機自己呼叫，你也可以手打。每一段的「呼叫方式」都會寫明是哪一種。

想看這個外掛 1.2.3 版的完整用法、劇本和常見的坑，請讀 AI Agent 開發流程實戰。它依 1.2.3 撰寫、涵蓋 25 支 skill，和這一頁分開維護。
