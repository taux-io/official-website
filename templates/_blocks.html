Import what a page uses on its first line: {% from "_blocks.html" import cover, faq -%} The `-%}` matters: without it the import leaves an empty line at the top of the rendered page. Every argument is content — a heading, a number, a question. None of them lands in a class or an href (design rule 37, `no parameterised markup`): the rules that read class attributes read this file, and they could not see a class a caller passed. A variant that needs different classes is a boolean here choosing between spelled-out strings, never a string from the caller.
